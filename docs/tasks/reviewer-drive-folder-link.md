# Reviewer Drive Folder Link

## Problem

Сейчас для доступа к папке ревьюера нужен Google Drive folder id. Пользователю неудобно вручную доставать id из ссылки на папку.

## Desired Behavior

Пользователь отправляет полную ссылку на Google Drive папку ревьюера, например `<reviewer-drive-folder-url>`. Бот сам извлекает идентификатор папки из ссылки и использует его в workflow. В коде, env examples и документации не должны появляться реальные Google Drive IDs.

## Current Context

Нужно добавить поддержку ссылки на папку, доступную ревьюеру. Правило проекта запрещает коммитить реальные Google Drive, Docs, Forms, Calendar и другие external resource IDs.

## Plan

- Найти, где сейчас хранится и используется folder id для ревьюера.
- Добавить парсинг Google Drive folder URL в одном месте.
- Поддержать существующий формат folder id, если он уже используется в конфигурации.
- Обновить сообщения/документацию так, чтобы пользователь отправлял ссылку, а не вручную извлекал id.
- Добавить тесты на типичные ссылки Google Drive folders и невалидные ссылки.

## Tests

- Полная ссылка Google Drive folder корректно превращается в folder id.
- Уже переданный folder id продолжает работать, если это нужно для обратной совместимости.
- Невалидная ссылка дает понятную ошибку.
- В репозитории нет реальных Google Drive IDs.

## Risks

- Форматы ссылок Google Drive могут отличаться.
- Нельзя начать принимать произвольные URL без валидации домена и типа ресурса.
