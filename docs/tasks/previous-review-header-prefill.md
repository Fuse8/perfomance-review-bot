# Previous Review Header Prefill

## Problem

Новый отчет Performance Review пока не умеет надежно переносить поля из
предыдущего отчета, поэтому часть шапки приходится заполнять вручную.

## Desired Behavior

- Из предыдущего review document копируются `Должность`, `Работает с` и дата
  предыдущего ревью.
- Если поле не найдено или предыдущего ревью нет, workflow оставляет поле
  пустым или ставит согласованный маркер.
- Создание нового отчета не ломается без предыдущего ревью.

## Current Context

Workflow уже ищет предыдущий review report и передает ссылку в создание нового
отчета. Нужно исследовать чтение Google Docs content и формат текущих шаблонов.

## Plan

- Исследовать структуру предыдущего Google Docs отчета через Docs API.
- Определить стабильный способ найти значения в шапке документа.
- Добавить extraction для `Должность`, `Работает с`, `Дата этого ревью`.
- Передавать найденные значения в copy/fill нового отчета.
- Для отсутствующих значений использовать пустое значение или маркер.

## Tests

- `pnpm test:quiet`
- Поля шапки заполняются из предыдущего отчета, если они найдены.
- Без предыдущего отчета workflow продолжает создавать новый отчет.
- Некорректный или неожиданный формат прошлого документа не роняет workflow.

## Risks

- Google Docs structure может быть нестабильной для таблиц и форматирования.
- Слишком жесткий парсинг может ломаться при изменении шаблона.
