# Пропуск неактуальных задач подготовки ревью

Created: 2026-10-21

Completed: 2026-10-21

## Цель

Не создавать задачи подготовки ревью, если их срок уже наступил,
и показывать в плане этапы, которые нужно выполнить сейчас.

## Что должно работать

- Для сбора отзывов, проверки и подготовки создавать задачи только на будущие даты.
- Если расчётная дата сегодня или раньше, задачу не создавать и показывать этап
  сверху в блоке «План»: «сегодня → Проверка отзывов (задачу не создавал,
  нужно сделать сейчас)». Не добавлять ссылку для несозданной задачи.
- Будущие созданные задачи показывать как раньше: дата, название и доступная ссылка.
- Сохранять пропущенные по сроку этапы в плане при частичном сбое Google Tasks.
  Не выдавать ошибки создания или недоступность сервиса за пропуск по сроку.
- Убрать отдельное пояснение о пропуске сбора, чтобы не дублировать строки плана.
- Не отправлять формы автоматически и не менять настройки напоминаний.

## Техническая реализация

- Рассчитывать даты существующей `buildReviewerReminderDate` с переносом выходных.
  Сравнивать с текущей датой по Челябинску (`Asia/Yekaterinburg`). Время
  не учитывать: публичный Google Tasks API его не поддерживает.
- До обращения к Google Tasks разделять этапы на пропущенные по сроку и будущие.
  Передавать виды и расчётные даты пропущенных этапов в результат и частичную ошибку.
- Сначала выводить пропущенные этапы, затем созданные задачи и встречу.
- Обновить соответствующее правило продуктовой спецификации.

## Верификация

- Проверить вчера, сегодня и завтра для всех трёх видов задач; границу суток
  по Челябинску, нулевые интервалы и перенос выходных.
- Проверить отсутствие запросов создания Google Tasks, когда все этапы уже наступили.
- Проверить порядок плана, отсутствие ссылок у пропущенных этапов,
  сохранение дат и ссылок будущих задач, отсутствие дублирующего пояснения.
- Проверить план при успешном результате и частичном сбое, отсутствие
  ложной пометки при недоступности Google Tasks или ошибке создания будущей задачи.
- После реализации выполнить `pnpm format`, `pnpm eslint:fix`,
  `pnpm type-check`, `pnpm test:quiet`.
