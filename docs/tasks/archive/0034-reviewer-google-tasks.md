# Задачи перед ревью без времени

Created: 2026-10-05
Completed: 2026-10-05

## Цель

Заменить мероприятия подготовки к новым ревью личными Google Tasks ревьюера.

## Что должно работать

- Три задачи с датой без времени в стандартном списке ревьюера.
- Сохранить интервалы и перенос выходных назад; создавать задачи на сегодня, пропускать прошедшие даты по Челябинску.
- Сохранить встречу ревью и существующие мероприятия.
- Проверять доступ к Tasks до создания материалов; сообщать о частичном результате при сбое.

## Техническая реализация

- Выделить модуль Google Tasks и добавить OAuth scope tasks.
- Убрать время из настроек, сохранив старое значение в хранилище без миграции.
- Обновить сообщения, настройку Google Cloud и тесты.

## Верификация

- Успешно: `pnpm format`, `pnpm eslint:fix`, `pnpm type-check`, `pnpm test:quiet` (161 тест).
- Успешно: `git diff --check`.
- Проверено на сохранённом токене: Google сообщил об отсутствии scope Tasks;
  работающий `/review` вернул HTTP 200 и диалог «Нужно обновить доступ к Google»
  с кнопкой авторизации.
- После повторной авторизации проверить задачи в Google Tasks и календаре вручную.

## Результат

Реализовано. Новые ревью создают личные задачи Google Tasks с датой без времени;
встреча остаётся мероприятием. Время скрыто из настроек, старое значение
сохранено в хранилище. Доступ к Tasks проверяется до создания материалов.
При частичном сбое бот показывает созданные задачи и ссылки на материалы
и встречу, не перезапуская создание.

По результатам ревью исправлено открытие `/review` без настроенной папки:
показывать диалог с инструкцией выполнить `/settings`, сохранить настройки
и повторить `/review` вместо обычного текстового ответа.

По результатам ревью добавлена проверка всех обязательных OAuth-разрешений
при открытии `/review`, перед созданием материалов и после OAuth. При
недостаточных правах показывать повторную авторизацию; временная сетевая
ошибка не удаляет сохранённый токен. Неполный набор разрешений после OAuth
не заменяет существующий токен.

Пользователь подтвердил готовность 2026-10-05. Задача перенесена в архив.
Версия повышена до `0.1.6`. Создание задач в Google после повторной
авторизации отдельно не проверялось агентом.
