# 0026 Обновить вывод workflow Performance Review

Created: 2026-06-09
Completed: 2026-08-19

## Цель

Сделать запуск и результат workflow Performance Review понятными и компактными в Google Chat и Calendar.

## Что должно работать

- Кнопка запуска workflow называется «Запустить ревью».
- Стартовое сообщение предупреждает, что подготовка обычно занимает около минуты.
- Итоговое сообщение содержит инструкции для папки, встречи, форм и отчёта.
- Ссылками являются названия разделов; отдельные строки «Открыть...» не выводятся.
- Дедлайн заполнения отчёта совпадает с датой этапа подготовки к встрече.
- Блок клиентской формы выводится только когда она создавалась.
- Встреча с сотрудником содержит только ссылку на доступный ему отчёт.
- Личные напоминания ревьюера содержат русские кликабельные названия всех рабочих ссылок.
- Между ссылками в напоминаниях есть пустая строка, необязательные ссылки выводятся только при наличии.

## Техническая реализация

- Использовать синтаксис `<url|название>` для ссылок в Google Chat.
- Формировать Calendar-ссылки через HTML отдельно для встречи и напоминаний.
- Во встрече выводить только отчёт; в напоминаниях сохранить порядок ссылок: папка, отчёт, внутренняя форма, клиентская форма, предыдущее ревью.
- Не менять OAuth, содержимое Google Docs, даты, timezone, участников и названия событий.

## Верификация

- Проверить полный финальный текст со всеми артефактами и вариант без клиентской формы.
- Проверить дедлайн отчёта, рассчитанный из количества дней до подготовки.
- Проверить, что встреча содержит только отчёт, а напоминания — полный набор доступных ревьюеру ссылок.
- Выполнить форматирование, lint, type-check и полный набор тестов.

## Результат

Обновлены запуск и итоговый текст Performance Review в Google Chat: добавлена кнопка «Запустить ревью», оценка времени выполнения, инструкции и кликабельные заголовки без длинных URL. Дедлайн отчёта берётся из этапа подготовки к встрече. Во встрече с сотрудником остаётся только ссылка на отчёт; полный набор рабочих ссылок сохраняется в личных напоминаниях ревьюера. Все проверки, ESLint и type-check прошли.
