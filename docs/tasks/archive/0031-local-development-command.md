# 0031 Единый запуск локальной среды

Created: 2026-08-18
Completed: 2026-08-18

## Цель

Запускать локальную базу данных, приложение и ngrok одной командой.

## Что должно работать

- `pnpm dev` поднимает PostgreSQL перед запуском приложения.
- Приложение и ngrok работают параллельно.
- `Ctrl+C` завершает приложение и туннель, не останавливая PostgreSQL.
- Миграции остаются отдельной явной командой.

## Техническая реализация

- Добавить `concurrently` в dev-зависимости.
- Сохранить отдельный запуск приложения как `dev:server`.
- Сделать npm-скрипт `dev` единым запуском с именованными процессами приложения и туннеля.
- Удалить устаревший `scripts/dev-local.sh`, дублирующий загрузку `.env` и запуск сервера.
- Описать команду в README.

## Верификация

- Запустить `pnpm dev` и проверить PostgreSQL, `localhost:8080` и публичный URL ngrok.
- Выполнить форматирование, ESLint, проверку типов и тесты.

## Результат

Добавлена единая команда `pnpm dev` для запуска PostgreSQL, приложения и ngrok.
Отдельный запуск сервера доступен через `pnpm dev:server`, устаревший
`scripts/dev-local.sh` удален. Проверки форматирования, ESLint, TypeScript и 105
тестов успешно пройдены.
