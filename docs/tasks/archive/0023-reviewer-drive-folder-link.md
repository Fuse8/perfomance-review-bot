# Reviewer Drive Folder Link

Created: 2026-07-01
Completed: 2026-08-18

## Цель

Разрешить пользователю вставлять ссылку на папку Google Drive в `/settings`, не извлекая folder ID вручную.

## Что должно работать

- Бот принимает стандартные ссылки Google Drive на папку, включая вариант с `/u/<number>/` и query-параметрами.
- Бот извлекает folder ID, проверяет доступ к папке и сохраняет настройки ревьюера.
- В форме настроек отображается ссылка на ранее сохраненную папку.
- Невалидная ссылка дает понятную ошибку и не закрывает диалог.

## Техническая реализация

- Добавить централизованные функции разбора и формирования ссылки Google Drive.
- Извлекать folder ID при обработке `/settings` до проверки доступа и сохранения настроек.
- Обновить форму, сообщения и документацию: пользователь работает со ссылкой, внутренний workflow — с folder ID.
- Не добавлять реальные идентификаторы внешних ресурсов в репозиторий.

## Верификация

- Проверить ссылки с query-параметрами, `/u/<number>/`, допустимыми символами ID и завершающим `/`.
- Проверить отклонение HTTP, посторонних доменов, ссылок не на папку, resource key и сырого folder ID.
- Проверить сохранение извлеченного ID, повторное отображение ссылки и обработку недоступной папки.
- Выполнить `pnpm format`, `pnpm eslint:fix`, `pnpm type-check`, `pnpm test:quiet`.

## Результат

Команда `/settings` принимает ссылку на папку Google Drive, извлекает ID для Drive API и показывает пользователю ссылку при повторном открытии настроек. Добавлены проверки формата, тесты и обновлена документация.
