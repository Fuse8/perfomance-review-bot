# Шаблоны сообщений участникам ревью

Created: 2026-10-05
Completed: 2026-10-05

## Цель

Добавить готовые сообщения коллегам, клиенту и сотруднику в результат создания ревью.

## Что должно работать

- Главный заголовок «Performance Review — {ФИО}», «План:», «Сообщения для отправки» и подписи получателей выделены жирным.
- Заголовок ревью и дата идут подряд без пустой строки; перед планом сохраняется пустая строка.
- Тексты компактные, без пустых строк внутри шаблона; дедлайн выделен жирным.
- Дедлайн отзывов — предыдущий рабочий день перед проверкой отзывов; саморевью — перед подготовкой к PR.
- Даты рассчитываются из настроек независимо от создания Google Tasks. Рабочие дни — понедельник–пятница, без учёта праздников.
- Запросы отзывов содержат ссылку респондента; клиентский блок появляется только при включённой клиентской форме.
- Саморевью использует созданный отчёт. Автоматической отправки и сокращения ссылок нет.
- При недоступности ссылки респондента выводится инструкция получить её вручную, без подстановки ссылки редактора.

## Техническая реализация

- Получить responderUri через Google Forms API после создания и настройки формы; сохранить отдельно от webViewLink.
- Рассчитать дату задачи существующей buildReviewerReminderDate, затем предыдущий рабочий день той же функцией.
- Добавить блоки в успешный результат и результат частичного сбоя Google Tasks; заменить старую подсказку о сроке саморевью.
- Настройки и схема БД не изменяются; изменения задачи 0037 сохраняются.

## Верификация

- Выполнены format, eslint:fix, type-check и test:quiet через `pnpm with current`: закреплённая версия pnpm зависла при обычном запуске, использован установленный pnpm 12.5.1. Node.js 24.21.0.
- Все 171 тест прошли; git diff --check без ошибок.
- Проверены полный итоговый текст, ссылки респондентов, отсутствие клиентского блока, ручная подсказка при сбое Forms API, отсутствие и частичный сбой Google Tasks.
- Проверены понедельник, вторник, перенос задачи с выходного, границы месяца/года и високосный февраль.
- Настоящие Google Forms API и отображение/копирование в Google Chat не проверены автоматически; пользователь подтвердил готовность задачи.

## Результат

Заголовки и подписи получателей выделены жирным; текст шаблонов и переносы строк сохранены. Реализованы три компактных шаблона с дедлайнами по рабочим дням и отдельными ссылками респондентов. Старая подсказка о заполнении отчёта заменена шаблоном саморевью. Пользователь подтвердил готовность 2026-10-05. Задача перенесена в архив, версия повышена до `0.1.10`.
