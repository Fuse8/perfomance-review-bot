# Единый формат времени ревью

Created: 2026-10-05
Completed: 2026-10-05

## Цель

Явно указывать часовой пояс в сообщении о создании ревью.

## Что должно работать

- Дата ревью выводится в формате `09.10.2026, 15:00 (Челябинск, UTC+5)`.
- Поле выбора времени ревью и подсказки ввода остаются прежними.
- Даты без времени и технический формат Google Calendar не меняются.

## Техническая реализация

Добавить суффикс ` (Челябинск, UTC+5)` в существующий форматтер
`formatChatFullDateTime`. Источник даты уже использует часовой пояс Челябинска;
преобразование даты и времени не требуется. Обновить ожидаемый текст сообщения
в тесте успешного создания ревью.
