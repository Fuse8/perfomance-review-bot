# README Format Skill

Completed: 2026-07-01

## Problem

Нужен единый формат README, чтобы документация проекта была структурирована одинаково и не расходилась между AI-инструментами и людьми.

## Desired Behavior

В проекте есть скилл, который задает единый формат README и документации. Его можно применять к текущему README и будущим изменениям документации.

## Current Context

Канонический формат живет в `.agents/skills/readme-docs-structure/SKILL.md`. README нужно привести к формату первого входа в проект, а справочные детали держать в `docs/`.

## Plan

- Использовать `.agents/skills/readme-docs-structure/SKILL.md` как канонический источник правил.
- Привести README к короткой структуре: описание, требования, быстрый старт, стек, команды, ссылки на docs.
- Вынести справочные детали в `docs/` и обновить индекс документации.
- Проверить ссылки, стиль и отсутствие реальных внешних ID.

## Tests

- README содержит обязательные разделы из skill.
- В проекте понятно, что каноническое правило лежит в `.agents/skills/readme-docs-structure/SKILL.md`.
- Ссылки из README и `docs/README.md` ведут на существующие файлы.
- Документация использует единый русский стиль.

## Risks

- Формат может конфликтовать с текущей структурой README.
- Если правило будет слишком общим, разные AI-инструменты продолжат интерпретировать его по-разному.

## Result

Добавлен канонический skill README/docs structure. README приведен к короткому входному формату, справочные детали вынесены в `docs/architecture.md` и `docs/testing.md`, индекс документации обновлен. Отдельный `docs/README.md` удален, корневой `README.md` стал единственной входной точкой документации.
