# Формат дат в отчёте ревью

Created: 2026-10-05
Completed: 2026-10-05

## Цель

Показывать полные даты в создаваемом отчёте ревью в формате `dd.MM.yyyy`.

## Что должно работать

- «Дата этого ревью», «Дата предыдущего ревью» и «Работает с» преобразуются из `yyyy-MM-dd` в `dd.MM.yyyy`.
- Уже оформленные даты, произвольный текст и `-` сохраняются без изменений.
- Форматы хранения, Google API, названий файлов и сообщений остаются прежними.
- Существующие документы автоматически не переписываются.

## Техническая реализация

В `src/drive.ts` добавить форматирование строк дат без преобразования часового пояса и применять его при подстановке трёх полей шаблона. Обновить ожидания существующей проверки заполнения шаблона.

## Верификация

- `pnpm with current format` — успешно.
- `pnpm with current eslint:fix` — успешно.
- `pnpm with current type-check` — успешно.
- `pnpm with current test:quiet` — 161 тест в 10 файлах прошёл.
- Отдельная проверка форматтера: ISO-дата, високосная дата, уже оформленная дата, произвольный текст, `-` и пустая строка — успешно.
- Создание реального Google-документа не проверялось.
