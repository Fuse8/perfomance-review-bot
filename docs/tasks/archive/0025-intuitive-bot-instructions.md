# Intuitive Bot Instructions

Created: 2026-07-01
Completed: 2026-08-19

## Problem

Сейчас пользователю нужна отдельная инструкция из документов, чтобы понять, как работать с ботом. Это создает лишний ручной шаг и риск, что инструкция устареет.

## Desired Behavior

Бот сам дает нужные инструкции в нужный момент. Работа с ним должна быть интуитивной: пользователь понимает доступные команды, следующий шаг, обязательные данные и результат без чтения отдельного документа.

## Current Context

Пользователь пришлет текущую инструкцию из документов позже и затем удалит ее. Нужно перенести полезные сценарии из документа в поведение бота и короткие подсказки.

## Plan

- Получить текущую инструкцию из документов.
- Разобрать ее на пользовательские сценарии и обязательные подсказки.
- Найти места в боте, где инструкции должны показываться автоматически.
- Обновить `/info`, стартовые сообщения, ошибки валидации и подсказки по следующему шагу.
- Удалить зависимость от внешней инструкции после переноса смысла в UX бота.

## Tests

- Новый пользователь может понять базовый сценарий из сообщений бота.
- Ошибки ввода объясняют, что исправить.
- `/info` остается коротким, но покрывает ключевые команды и сценарии.

## Risks

- Можно перегрузить чат длинными сообщениями.
- Инструкции в боте должны оставаться актуальными при изменении workflow.

## Result

Приветствие и `/info` переведены на единый компактный формат: описание бота, команды, подготовка первого ревью, ссылки на шаблоны, структура папок и часовой пояс. Статус OAuth и ссылка на авторизацию формируются динамически, а в `/settings` шаблоны доступны только для просмотра. Поведение закреплено тестами.
