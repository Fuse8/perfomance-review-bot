# Documentation Knowledge Base

Completed: 2026-06-08

## Problem

Старый `PLAN.md` смешивал исторический MVP-план, текущий backlog и детали реализации. Документации не хватало структуры для дальнейшего расширения и накопления контекста.

## Desired Behavior

Актуальные задачи должны жить в `docs/tasks/`, завершенные задачи - в `docs/tasks/archive/`. `docs/roadmap.md` должен оставаться коротким входом в текущие направления работ.

## Current Context

Реорганизация выполнялась после завершения MVP-сценария. Старый MVP-план сохранен как исторический документ.

## Plan

- Перенести старый `PLAN.md` в архив планов.
- Добавить `docs/roadmap.md` как актуальный вход в планирование.
- Создать task-файлы для текущих направлений доработки.
- Добавить правила работы с документацией.

## Tests

- Проверить наличие новых файлов документации.
- Проверить отсутствие ссылок на старые пути.
- Проверить, что архивный MVP-план сохранен.

## Risks

- Можно потерять исторический контекст старого плана.
- Можно размыть различие между активными задачами и архивом.

## Result

- Перенесен старый `PLAN.md` в `docs/tasks/archive/2026-06-08-mvp-implementation-plan.md`.
- Добавлен новый вход в планирование: `docs/roadmap.md`.
- Добавлены task-файлы для текущих направлений доработки.
- Добавлены `docs/README.md`, `docs/decisions.md` и архивный README.
