# Employee Folder Auto Create

Created: 2026-07-01

## Problem

Когда бот проверяет наличие папки сотрудника и не находит ее, пользователю приходится разбираться с этим вручную.

## Desired Behavior

Если папка сотрудника не найдена, бот автоматически создает ее и сообщает: папка сотрудника не найдена, папка создана автоматически. Если папка уже есть, бот явно подсвечивает, что папка найдена.

## Current Context

Workflow уже работает с Google Drive артефактами. Нужно найти текущую проверку папки сотрудника и изменить поведение без нарушения прав доступа и текущей структуры Drive.

## Plan

- Найти код, который ищет папку сотрудника в Google Drive.
- Определить родительскую папку и правила именования для новой папки сотрудника.
- Добавить автоматическое создание папки при отсутствии.
- Обновить chat output: отдельные статусы для найденной и автоматически созданной папки.
- Добавить тесты на оба сценария.

## Tests

- Если папка сотрудника существует, новая папка не создается, а бот сообщает, что папка найдена.
- Если папки нет, бот создает ее в правильном месте и сообщает об автоматическом создании.
- Ошибка прав доступа к Drive остается понятной и не маскируется как успешное создание.

## Risks

- Возможны дубликаты папок при несовпадении имени или гонках запросов.
- Нужна аккуратная обработка прав доступа, чтобы бот не создавал папку в неправильном месте.
