# 0030 Организовать active и archive как в Pokkels

Created: 2026-08-18

# Цель

Сделать структуру и жизненный цикл проектных задач такими же, как в соседнем репозитории Pokkels.

# Что должно работать

- Активные задачи хранятся в `docs/tasks/active/`.
- Завершенные задачи хранятся в `docs/tasks/archive/`.
- Roadmap активных задач расположен в `docs/tasks/roadmap.md`.
- Задачи имеют сквозные четырехзначные номера.
- Архивный `README.md` содержит ссылки на завершенные задачи.
- Правила создания, реализации, ревью и архивирования описаны в проектной документации.

# Техническая реализация

- Перенести существующие task-файлы без потери содержимого.
- Сохранить исторические даты завершения и даты создания активных задач.
- Обновить ссылки в README, workflow, ADR и правилах для агентов.
- Удалить прежние индексы задач, которые больше не являются источником правды.

# Верификация

- Проверить структуру каталогов.
- Проверить относительные Markdown-ссылки.
- Запустить форматирование документации.
