# End To End Testing Contour

## Problem

Нужно максимально закрыть контур тестирования workflow Performance Review: от
заполнения Google Chat формы до проверки созданных артефактов.

## Desired Behavior

- Тестовый сценарий запускает workflow так, как пользователь делает это в
  Google Chat.
- Проверяются созданные Google Drive файлы, формы, календарная встреча и задачи.
- После выполнения задачи исполнитель сам проверяет, что сценарий реально
  работает end-to-end.
- Тестовый контур можно запускать повторно без ручной чистки данных.

## Current Context

Сейчас проект покрыт unit/integration тестами с моками Google API. Нужно
определить, какой уровень end-to-end проверки возможен безопасно: локальный
контур с моками Google API, staging Google project, ручной smoke checklist или
комбинация этих подходов.

## Plan

- Найти текущие тесты Google Chat workflow, Drive, Calendar, Forms и storage.
- Определить минимальный e2e сценарий: запуск `/review`, заполнение формы,
  submit, создание всех артефактов, проверка результата.
- Выбрать безопасный тестовый контур: локальные моки, staging окружение или
  гибрид.
- Добавить проверку созданных файлов/форм/календарных событий после submit.
- Добавить инструкцию запуска e2e проверки и требования к тестовым credentials,
  если они нужны.
- После реализации выполнить сценарий и зафиксировать результат проверки.

## Tests

- Workflow проходит от Google Chat event до итогового сообщения без ручных
  действий внутри кода.
- Проверяется, что создана Drive folder.
- Проверяется, что созданы нужные документы/формы.
- Проверяется, что создана календарная встреча.
- Проверяется, что созданы reviewer tasks/reminders.
- Проверяется, что повторный запуск не ломается из-за оставшихся тестовых
  данных.

## Risks

- Реальный e2e с Google API требует credentials и может создавать данные в
  production/staging аккаунтах.
- Нужно избежать случайной отправки сообщений или приглашений реальным людям.
- Полностью автоматический e2e может быть хрупким из-за внешних Google API.
- Может понадобиться отдельное staging окружение и тестовый Google Chat space.
