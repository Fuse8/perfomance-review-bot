# Chat Commands Info Timezone

## Problem

Команды Google Chat нужно актуализировать: `/check-auth` больше не нужен, а `/info`
не объясняет, что даты и время ревью создаются по челябинскому времени.

## Desired Behavior

- Команда `/check-auth` удалена из доступных команд и подсказок.
- `/info` показывает, что ревью, встреча и задачи создаются по челябинскому времени.
- Текст команд остаётся коротким и понятным.

## Current Context

Команды и help-текст находятся в Google Chat workflow. Перед изменениями нужно
найти обработчики команд и текущий output `/info`.

## Plan

- Найти регистрацию и обработку `/check-auth`.
- Удалить `/check-auth` из help/output и кода, если команда больше не используется.
- Обновить текст `/info`, добавив упоминание челябинского времени.
- Обновить тесты команд.

## Tests

- `/info` содержит упоминание челябинского времени.
- `/info` не показывает `/check-auth`.
- Удаление `/check-auth` не ломает остальные команды.

## Risks

- Команда может быть зарегистрирована не только в коде, но и в настройках Google Chat app.
- Формулировка timezone должна быть понятной пользователям и не конфликтовать с
  технической timezone календаря.

## Result

Реализовано:

- `/check-auth` удалена из runtime routing, dependency injection и документации.
- Diagnostic-модуль `/check-auth` и его тесты удалены как неиспользуемые.
- `/info` сообщает, что даты и время ревью, встречи и задач создаются по
  челябинскому времени, и выводится в новом компактном формате.
- Тесты `/info` обновлены: проверяют timezone-текст и отсутствие `/check-auth`.
- При добавлении бота в чат первым ответом выводится `/info`, а ссылка на
  авторизацию отправляется отдельным вторым сообщением.
