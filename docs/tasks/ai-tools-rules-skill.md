# AI Tools Rules Skill

## Problem

Нужно унифицировать правила работы с разными AI-инструментами, чтобы Codex, другие ассистенты и люди следовали одинаковому workflow.

## Desired Behavior

В проекте есть единая инструкция или скилл, который описывает общие правила работы AI-инструментов: как читать контекст, создавать задачи, вносить изменения, проверять результат и работать с git.

## Current Context

Точные правила пользователь пришлет позже. Сейчас в проекте уже есть AGENTS.md-инструкции и task workflow, которые нужно сохранить совместимыми.

## Plan

- Получить от пользователя целевой набор правил для AI-инструментов.
- Сравнить новые правила с текущими AGENTS.md и проектными workflow.
- Выбрать место хранения: skill, AGENTS.md, отдельный документ или комбинация.
- Убрать дублирование и противоречия между инструкциями.
- Проверить, что правила применимы для Codex и других AI-инструментов.

## Tests

- Новые правила не противоречат task workflow.
- Инструкция явно описывает, что делать до реализации, после проверки и перед git staging/commit.
- Для разных AI-инструментов есть единый источник истины или понятная схема приоритетов.

## Risks

- Можно случайно создать конфликт между AGENTS.md и новым скиллом.
- Слишком подробные правила могут стать трудными для поддержки.
