# README Format Skill

## Problem

Нужен единый формат README, чтобы документация проекта была структурирована одинаково и не расходилась между AI-инструментами и людьми.

## Desired Behavior

В проекте есть скилл, который задает единый формат README и документации. После получения финального формата его можно применять к текущему README и будущим изменениям документации.

## Current Context

Финальный формат README будет передан позже. Сейчас нужно зафиксировать задачу и место, куда добавлять требования.

## Plan

- Получить от пользователя целевой формат README.
- Определить, должен ли формат жить как Codex skill, проектная инструкция или документированный шаблон.
- Добавить скилл/инструкцию в проект.
- Применить формат к README, если пользователь подтвердит миграцию текущего файла.
- Обновить документацию процесса, чтобы будущие изменения README использовали этот формат.

## Tests

- README соответствует утвержденному формату.
- В проекте понятно, где лежит правило формата README.
- Новые изменения README можно проверить по этому правилу.

## Risks

- Формат может конфликтовать с текущей структурой README.
- Если правило будет слишком общим, разные AI-инструменты продолжат интерпретировать его по-разному.
