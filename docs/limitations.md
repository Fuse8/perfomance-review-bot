# Ограничения интеграций

## Время задач Google Tasks

Проверено: 2026-10-21.

- Публичный Google Tasks API отбрасывает время в `due`; создание и обновление
  сохраняют только дату. Apps Script это ограничение не обходит.
- Внутренний API Calendar с токеном бота вернул `403 SERVICE_DISABLED`,
  с ключом Calendar — `400 CONSUMER_INVALID` из-за разных Cloud-проектов.
  Включение приватной службы через Console недоступно для проверенного проекта.
- Через интерфейс Calendar время сохраняется, что проверено после перезагрузки.
  Автоматизация потребует авторизованного браузера; серверный способ не подтверждён.
- Для уведомлений по времени потребуется отдельный механизм: события Calendar
  или сообщения бота по расписанию. Настроек времени задач недостаточно.

## Таблицы ответов Google Forms

- Публичный Forms API не позволяет привязать Google Sheets для сбора ответов.
  Проверенный обход — Google Apps Script.
- Для привязки таблиц к двум формам потребовались Sheets API, Apps Script API
  и дополнительные OAuth-права `auth/spreadsheets` и `auth/forms`.
- Решение от 10.08.2026: отказаться от интеграции из-за сложности при небольшой
  пользе. Ответы доступны непосредственно в Google Forms.
