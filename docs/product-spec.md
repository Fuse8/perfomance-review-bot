Бот для проведения перфоманс ревью. Должен работать в гугл чате.

# Алгоритм запуска бота

1. Заполняем изначальные параметры:
   1. Имя и фамилия человека
   2. Планируемая дата ревью (с точностью до даты и времени по Члб)
   3. Нужно ли создавать отдельную форму для отзыва от клиента
2. Бот сканирует заранее заданную папку со всеми ревьюхами. Ищет по имени папку с человеком. Если папка не найдена, автоматически создает ее в корневой папке ревью и сообщает об этом пользователю
3. Бот сканирует пользователей fuse8, транслитит заданное на первом шаге имя и пытается найти человека. Если не находит, то задает вопрос с просьбой указать емэйл этого человека
4. Внутри папки ищет самый последний (по дате) документ ревью. Если такого документа нет, то задает доп. вопрос "Не было найдено предыдущее ревью. Продолжить без него?"
5. Создает все документы на гугл диске
6. Создает все необходимые встречи и задачи в гугл календаре
7. Выдается отчет по проделанной работе:
   1. Созданный "Отзыв Performance review (внутри компании fuse8)" со ссылкой опубликованную форму ответов
   2. Созданный "Отзыв Performance review (для заказчика)" со ссылкой опубликованную форму ответов
   3. Созданный "Отчёт Performance Review" со ссылкой на документ
   4. Краткая информация о созданной встречи для проведения PR (название, дата и время)
   5. Краткая информация о созданных задачах (название, дата и время)

Возможно нужна какя-то предварительная регистрация человека ревьюера, в рамках которой можно:

1. Связать с рабочим гугловым аккаунтом
2. Сделать настройки по созданию задач
3. Проверить/выдать доступ к календарю и возможно доступ к гугл диску через гугл аккаунт ревьюера

# Документы, которые необходимо создать на гугл диске

1. Создать в папке по человеку новую папку с датой предполагаемого ревью в формате "2026.12" (год и месяц)
2. Внутри этой папки создать от трех до пяти файлов. При создании в имя файла должно вставлять имя человека и предполагаемая дата ревью в формате "2026.12" (год и месяц)
   1. Отзыв Performance review (внутри компании fuse8).
      1. Создается на основе спец. шаблона
      2. Имя файла “{Имя и Фамилия} // Отзыв Performance review // {дата в формате “гггг-мм”}”
      3. Внутри файла заголовок задается в формате “{Имя и Фамилия} // Отзыв Performance review // {дата в формате “гггг-мм”}”
      4. Форма публикуется с доступом респондентов внутри компании fuse8
      5. Присылается ссылка на короткий урл этой формы
      6. Настраивается привязка ответов к новой Таблице
      7. На выходе получается два документа: сама форма и Таблица с ответами
   2. Отзыв Performance review (для заказчика). Отличается тем, что нет обязательности авторизации через гугл аккаунт. А шара происходит по ссылке
      1. Создается на основе спец. шаблона
      2. Имя файла “{Имя и Фамилия} // Отзыв Performance review от клиента // {дата в формате “гггг-мм”}”
      3. Внутри файла заголовок задается в формате “{Имя и Фамилия} // Отзыв Performance review от клиента // {дата в формате “гггг-мм”}”
      4. Форма публикуется с доступом респондентов по ссылке
      5. Присылается ссылка на короткий урл этой формы
      6. Настраивается привязка ответов к новой Таблице
      7. На выходе получается два документа: сама форма и Таблица с ответами
   3. Отчёт Performance Review
      1. Создается на основе спец. шаблона
      2. Ищется самый последний (по дате) документ ревью в корневой папке человека
      3. По возможности внутри документа заполняется шапка
         1. **Имя**
         2. **Должность** (копируется из предыдущего ревью, если есть. Иначе прочерк красного цвета, чтобы не забыть проставить)
         3. **Работает с** (копируется из предыдущего ревью, если есть. Иначе прочерк красного цвета, чтобы не забыть проставить)
         4. **Дата этого ревью** (берется из планируемой даты ревью)
         5. **Ссылка на предыдущее ревью** (если предыдущее найдено)
         6. **Дата предыдущего ревью** (берется из поля **Дата этого ревью** из предыдущего ответа, если предыдущее ревью найдено)
         7. **Ревьюверы** (имя текущего человека-ревьюера)
      4. Находит человека среди гугл аккаунтов и ему доступ выдается на редактирование.

# Встречи, которые необходимо создать в гугл календаре

1. Встреча для проведения PR в планируемую дату и время. Добавляет во встречу ревьюера (текущего пользователя), для кого проводится ревью, документ "Отчёт Performance Review". Время встречи 2,5 часа
2. По возможности создает задачи в календаре ревьюера. Параметры по датам и времени должны быть настраиваемыми (либо для всех одинаковые, но в идеале конкретными для ревьюера):
   1. За N дней до начала ревью (но в будний день) в определенное время создается задача "Запустить сбор отзывов для PR {Имя и Фамилия}".
   2. За N дней до начала ревью (но в будний день) в определенное время создается задача "Проверить отзывы для PR {Имя и Фамилия}".
   3. За N дней до начала ревью (но в будний день) в определенное время создается задача "Подготовиться к проведению PR {Имя и Фамилия}".
