# Development Workflow

## 1. Создаем задачу

Даем в чате контекст задачи и просим создать задачу.

## 2. Открываем новый чат и планируем задачу

Включаем plan mode. В сообщении указываем, с какой задачей работаем, например:

```text
Делаем задачу docs/tasks/active/0030-example-task.md. Сначала исследуй и предложи план, без реализации.
```

План редактируем столько итераций, сколько нужно. В конце должен получиться
итоговый план.

## 3. Реализовываем задачу по плану

После согласования плана нажимаем реализовать план. Во время реализации вносим правки по необходимости.

## 4. Делаем ревью

После реализации просматриваем `git diff`. Если нужны правки, вносим их в этом же чате и снова проверяем измененную часть.

## 5. Завершаем задачу

Когда задача принята, пишем в чат, что задача готова. После этого task-файл переносится из `docs/tasks/active/` в `docs/tasks/archive/`, получает дату завершения и добавляется в архивный список.

## 6. Commit и deploy

После явного подтверждения готовности задачи агент создает Conventional Commit. Номер задачи указывается сразу после типа, например:

```text
docs: 0030 organize task workflow
```

Пушим в `main`, запускается автоматический deploy. Или делаем другие задачи и копим их для одного деплоя.
