## Стоимость Google API

При ~100–200 ревью в месяц (10–30 в день) все используемые API **бесплатны**:

| API | Тарификация | Квота |
|-----|-------------|-------|
| Google Drive API | Бесплатно | 12 000 запросов/минуту |
| Google Docs API | Бесплатно | 300 запросов/минуту |
| Google Chat API | Бесплатно | 3 000 запросов/минуту |

На одно ревью сейчас ~6 Drive/Docs вызовов → 200 ревью/месяц = ~1 200 запросов.
Это на порядки ниже любых лимитов.

Что может стоить денег (но тоже в пределах бесплатных tier):
- **Firestore** при `STORAGE_DRIVER=firestore`: бесплатно до 50 000 чтений/20 000 записей в день
- **Cloud Run** при деплое туда: бесплатно до 2M запросов/месяц
- **VPS** — платишь только за саму машину, не Google

При деплое на VPS с `STORAGE_DRIVER=local` Google API ничего не стоят.
